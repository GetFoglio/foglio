# Contributing to Foglio

Thanks for your interest in Foglio! Bug reports, ideas and pull requests are all welcome.
Issues and discussions may be written in English or Italian.

## Getting started

1. Install the prerequisites described in the [README](README.md#building-from-source)
   (Xcode Command Line Tools and Rust via `rustup`).
2. Build a development copy for your machine only, which is faster than the universal build:

   ```sh
   scripts/build.sh --arm64-only
   open build/Foglio.app
   ```

3. Run the Rust core's tests:

   ```sh
   cargo test --manifest-path core/Cargo.toml
   ```

## Project layout

| Path        | What lives there                                                   |
|-------------|--------------------------------------------------------------------|
| `core/`     | Rust static library: workbook model, IronCalc engine, file formats |
| `core/include/foglio_core.h` | The C ABI between the core and the app            |
| `app/`      | Swift/AppKit application (`Sources/`, `Info.plist`)                |
| `scripts/`  | `build.sh`, `package.sh`, `make_icon.swift`                        |
| `assets/`   | App icon (generated by `scripts/make_icon.swift`)                  |

## Guidelines

- **Keep it light.** Foglio's point is to be small and fast. Please discuss new dependencies
  (Rust crates or Swift packages) in an issue before adding them.
- **Keep the C ABI small and explicit.** Any change to `core/include/foglio_core.h` must be
  matched in `core/src` and the Swift callers in the same pull request. Memory returned by the
  core is freed by the matching `foglio_*_free` function.
- **Stay native.** UI work uses AppKit and follows the macOS Human Interface Guidelines
  (menus, keyboard shortcuts, dark mode, accessibility).
- **Format your code.** Run `cargo fmt` and `cargo clippy` for Rust; follow the existing style
  in the Swift sources.
- **Small, focused pull requests** with a clear description are easier to review. Include a
  test for core changes where practical, and a screenshot for visible UI changes.
- **Never commit real-world spreadsheets that contain personal or confidential data** as
  test fixtures.

## Reporting bugs

Please include your macOS version, your Mac's chip (Apple silicon or Intel), the Foglio
version (or commit), steps to reproduce, and — if possible — a small file that shows the
problem.
